# Squadra Corsa

A Three.js website showcasing Ferrari Formula 1 and endurance race cars with interactive 3D models, specs, photo galleries, and unveiling videos.

Live demo: https://amirtterk.github.io/Ferrari-website/

## Cars

- Ferrari SF-23
- Ferrari SF90
- Ferrari SF70H
- Ferrari F2012
- Ferrari 499P

## Features

- Interactive 3D model viewer with orbit controls for each car
- Technical specs per car (engine, displacement, weight, power)
- Photo gallery with full-size modal view
- Unveiling video player
- Responsive layout with mobile navigation drawer
